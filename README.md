# ComfyUI workflows

Family-friendly ComfyUI workflows. Each folder has the workflow JSON (drag it into ComfyUI), a sample image, and a README listing every model file you need, where to download it, and the settings.

| Folder | What it makes | Base model |
|---|---|---|
| [malfoid](malfoid/) | Malfoid (FemDraco) – Anima | Anima |
| [maomao](maomao/) | Maomao (The Apothecary Diaries) – Pony | Pony |
| [megumin](megumin/) | Megumin (KonoSuba) – Anima | Anima |
| [anima_detailer](anima_detailer/) | Anima + Smooth Detailer Booster (Megumin example) | Anima |
| [anya_smug](anya_smug/) | Anya smug "heh" – Pony | Pony |
| [anya_peanuts](anya_peanuts/) | Anya eating peanuts – Pony | Pony |

Model and LoRA files are **not** included. Download them from the links in each README.
